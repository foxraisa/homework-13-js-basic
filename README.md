🚀 Менеджер параграфов - Полная версия с CI/CD
Простое веб-приложение для управления текстовыми параграфами с полной настройкой качества кода, автоматическим тестированием и деплоем на GitHub Pages.

✨ Особенности
✅ Интуитивный интерфейс - добавление и автоматическое управление параграфами

✅ Адаптивный дизайн - работает на компьютерах и мобильных устройствах

✅ Качество кода - ESLint + Prettier + Husky

✅ Автоматическое тестирование - Jest с полным покрытием кода

✅ CI/CD пайплайны - автоматические проверки при каждом коммите

✅ Автоматический деплой - приложение само публикуется на GitHub Pages

✅ Прекоммит-хуки - код проверяется перед каждым коммитом

🛠 Технологии
JavaScript (ES6+) - современный JavaScript

Webpack 5 - сборка проекта

Jest - фреймворк для тестирования

ESLint + Prettier - проверка качества и форматирование кода

Husky - прекоммит-хуки

GitHub Actions - CI/CD пайплайны

GitHub Pages - хостинг приложения

🚀 Быстрый старт
Установка и запуск
Клонируйте репозиторий

bash
git clone <your-repo-url>
cd paragraph-app
Установите зависимости

bash
npm install
Запустите в режиме разработки

bash
npm start
Приложение откроется в браузере по адресу: http://localhost:3000

Как использовать
Введите текст в поле ввода

Нажмите кнопку "Добавить параграф" или клавишу Enter

Новый параграф появится в списке

Когда параграфов станет больше 5, самый старый автоматически удалится

📋 Скрипты package.json
bash
# Разработка
npm start          # Запуск dev-сервера с hot-reload
npm run dev        # Сборка для разработки

# Продакшен
npm run build      # Сборка для продакшена

# Тестирование
npm test           # Запуск тестов
npm run test:watch # Тесты в режиме наблюдения
npm run test:coverage # Тесты с отчетом о покрытии

# Качество кода
npm run lint       # Проверка кода линтером
npm run lint:fix   # Автоисправление ошибок линтера
npm run format     # Форматирование кода
npm run format:check # Проверка форматирования

# Очистка
npm run clean      # Очистка папки dist
🧪 Тестирование
Проект включает полный набор автоматических тестов:

Запуск тестов
bash
npm test           # Однократный запуск
npm run test:watch # Режим наблюдения (автозапуск при изменениях)
npm run test:coverage # С отчетом о покрытии

Что проверяют тесты
✅ Кнопка активируется только когда есть текст

✅ Новые параграфы добавляются правильно

✅ Показываются ошибки при неправильном вводе

✅ Счетчик обновляется корректно

✅ Автоматически соблюдается лимит в 5 параграфов

🔍 Качество кода
Прекоммит-хуки
При каждом коммите автоматически запускаются:

ESLint - проверка синтаксиса и стиля кода

Prettier - автоматическое форматирование

Jest - запуск всех тестов

Ручная проверка
bash
npm run lint       # Проверить код
npm run lint:fix   # Исправить автоматически исправимые ошибки
npm run format     # Отформатировать код


🔄 CI/CD Пайплайны
1. CI Пайплайн (.github/workflows/ci-cd.yml)
Запускается при каждом пуше и пул-реквесте:

✅ Проверка кода линтером (ESLint)

✅ Проверка форматирования (Prettier)

✅ Запуск всех тестов (Jest)

✅ Сборка проекта (Webpack)

✅ Сохранение артефактов сборки

2. Деплой Пайплайн (.github/workflows/deploy.yml)
Запускается при пуше в main ветку:

🏗️ Сборка проекта

🧪 Запуск тестов

🚀 Автоматический деплой на GitHub Pages через окружение paragraph-app-production

🌐 Деплой
Приложение автоматически деплоится на GitHub Pages при пуше в main ветку.

URL продакшена: https://[ваш-username].github.io/[имя-репозитория]/

Настройка окружения
Зайдите в репозиторий на GitHub

Перейдите в Settings → Environments

Найдите окружение paragraph-app-production

При необходимости настройте правила развертывания
